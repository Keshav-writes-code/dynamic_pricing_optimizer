## Dynamic Pricing Optimizer

Predict what you should price your products based on some key factors :

- is weekend?
- demand ( customer requesting / units in inventory )
- competitor price
- hour (of day)

## What inspired me to build this

just a curiosity of how prices of products are dynamically altered to maximize revenue\
how can we make AI decide how to boost revenue with proof

## Specialities

this project is an End to End MLOps project (from training to production) that is deployed on Microsoft Azure
